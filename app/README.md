# CareLoop V2 — React Native / Expo Demo

This version expands the pitch flow:
Home → Create Patient → Prescription upload/OCR simulation → Verification → Activation → Reminder → Caregiver → Health → Nutrition → Consent/Safety.

All data is fictional and local to the demo. No real patient data, medical API, OCR service, notification service, or clinician connection is used.

Run with:
npm install
npx expo start

An Android APK still requires an Android build environment or cloud build service.
